# Project Statement

## Project Title

**Smart Student Management & Academic Performance System**

---

## 1. Problem Statement

Managing student and academic information manually can be time-consuming and difficult to maintain. Student details, course enrollments, marks, attendance, and academic performance may be stored in different places, making it harder to access, update, and analyze the information efficiently.

The **Smart Student Management & Academic Performance System** aims to provide a centralized console-based solution for managing these academic records. The system allows users to maintain student and course information, record academic data, calculate performance, and generate useful reports through a structured Java application.

---

## 2. Project Scope

The project focuses on developing a **pure Java, console-based student management system**.

The system covers:

* Student record management
* Course management
* Student course enrollment
* Marks management
* Attendance management
* CGPA calculation
* Academic performance analysis
* Student and academic report generation
* File-based data storage using Java I/O
* Database storage and CRUD operations using JDBC
* Input validation and exception handling

The application is limited to a console interface and does not include a graphical or web-based frontend.
